ProNeet Proxy

Términos y Condiciones

Bienvenido a ProNeet Proxy. Estos Términos y Condiciones establecen las reglas y condiciones aplicables al acceso y uso de nuestra aplicación. Te recomendamos leer detenidamente este documento antes de utilizar las funciones de conexión disponibles.

1. Aceptación de los Términos

Al aceptar estos Términos y Condiciones y utilizar ProNeet Proxy, el usuario manifiesta que ha leído y comprendido las disposiciones aquí descritas. Si no está de acuerdo con estas condiciones, puede rechazar su aceptación y abstenerse de utilizar la aplicación.

2. Descripción del Servicio

ProNeet Proxy es una aplicación de Android diseñada para facilitar la configuración y utilización de conexiones mediante protocolos proxy. Entre los métodos compatibles pueden encontrarse SOCKS5, HTTP y SSH (CDN). La aplicación proporciona herramientas para establecer conexiones, consultar su estado y visualizar información técnica relacionada con el funcionamiento de la red.

3. Configuración de Conexiones

Para utilizar determinadas funciones, puede ser necesario introducir una dirección IP o dominio, un puerto, un método de conexión y, cuando corresponda, credenciales de autenticación. El usuario es responsable de utilizar configuraciones válidas y de disponer de autorización para acceder a los servidores seleccionados.

4. Servidores y Servicios Externos

Las conexiones pueden depender de servidores administrados por terceros o de infraestructura ajena a ProNeet Proxy. La disponibilidad, velocidad, seguridad y condiciones de acceso de estos servidores pueden variar. Cuando el usuario utilice servicios independientes, también deberá respetar las normas establecidas por sus respectivos administradores.

5. Uso Permitido de la Aplicación

El usuario se compromete a utilizar ProNeet Proxy de forma responsable, respetando las leyes aplicables, los derechos de terceros y las condiciones de los servicios de red utilizados. La aplicación está destinada a proporcionar herramientas de conectividad y no debe emplearse para perjudicar sistemas, redes, personas o servicios.

6. Actividades No Permitidas

No está permitido utilizar la aplicación para realizar actividades ilegales, acceder sin autorización a sistemas informáticos, distribuir programas maliciosos o interferir deliberadamente con servicios de terceros. Tampoco debe utilizarse para infringir derechos de propiedad intelectual ni para realizar actividades prohibidas por la legislación aplicable.

7. Disponibilidad del Servicio

El funcionamiento de ProNeet Proxy depende de factores técnicos como la conectividad a Internet, el dispositivo, el sistema Android, la configuración utilizada y el estado del servidor seleccionado. Por esta razón, no se garantiza que todas las conexiones funcionen de manera permanente, sin interrupciones o con una velocidad determinada.

8. Seguridad y Privacidad

La aplicación permite utilizar diferentes métodos de conexión, pero el nivel de seguridad depende del protocolo y del servidor utilizado. No todos los métodos proxy ofrecen las mismas capacidades de cifrado y privacidad. El uso de ProNeet Proxy no garantiza anonimato absoluto ni protección frente a todos los riesgos de Internet. Se recomienda utilizar servidores confiables y servicios que incorporen mecanismos de seguridad adecuados.

9. Permisos del Sistema Android

ProNeet Proxy puede solicitar autorización para utilizar el servicio VPN de Android cuando sea necesario para dirigir el tráfico de red mediante las conexiones configuradas. Este permiso se emplea para habilitar las funciones de conectividad correspondientes y está sujeto a los controles y autorizaciones proporcionados por el sistema operativo.

10. Responsabilidad del Usuario

Cada usuario es responsable de la configuración que utilice, de las credenciales que proporcione y de las actividades que realice mediante su conexión. Debe asegurarse de contar con autorización para acceder a los servidores externos y tomar precauciones para proteger su información y sus dispositivos.

11. Limitaciones del Servicio

ProNeet Proxy se proporciona como una herramienta de conectividad. Pueden producirse interrupciones, bloqueos de red, incompatibilidades o fallos derivados del dispositivo, del proveedor de Internet o de servidores externos. En la medida permitida por la legislación aplicable, no asumimos responsabilidad por problemas originados exclusivamente en servicios de terceros que se encuentran fuera de nuestro control. Esta disposición no limita los derechos que la ley reconozca al usuario.

Algunas características pueden cambiar, incorporarse o dejar de estar disponibles cuando existan razones técnicas o de mantenimiento. Los cambios importantes en las condiciones de uso podrán reflejarse en una versión actualizada de este documento.

El uso de la aplicación no concede autorización para distribuir versiones modificadas, suplantar su identidad o utilizar indebidamente sus elementos distintivos.

14. Enlaces y Plataformas de Terceros

La aplicación y sus páginas informativas pueden contener enlaces a servicios externos, plataformas de comunicación y otros recursos. Estos servicios tienen sus propias condiciones de uso y políticas de privacidad. ProNeet Proxy no controla necesariamente el contenido, la disponibilidad o las prácticas de las páginas externas.

15. Política de Privacidad

El tratamiento de información relacionado con el funcionamiento de ProNeet Proxy se describe en nuestra Política de Privacidad.
